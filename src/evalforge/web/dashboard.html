How to use EvalForge

  1. Choose a saved test. The baseline is the reference version. The candidate is the changed version you are checking.
  2. Read the result. Passed means required checks were met. Blocked means a quality rule failed. Incomplete means an execution or evidence problem prevented a reliable decision.
  3. Review the questions. Compare both answers and expand their checks or source documents to understand what happened.
  4. Fix and test again. Change your application, documents or configuration, select Refresh setup, then Run evaluation. You can also run a test in the terminal and select Refresh results.
Create your first result

Choose the enabled support configuration above and select Run evaluation. To generate both a passing and blocked demonstration from the project folder:

python -m evalforge.demos.workflow

This uses rules, not AI. It intentionally creates a passing run and a blocked run to demonstrate how EvalForge catches mistakes.

Test actual model-generated RAG answers

Configure the model IDs in examples/rag/live.json and set the provider credential locally. The model and judge must support the configured endpoint. Select its configuration above, confirm model calls and select Run evaluation. Or run in the terminal:

evalforge run --config examples/rag/live.json

This example compares a complete document collection with one missing the refund policy. Calls may be paid. Refresh results after the run finishes.

Refresh results reloads saved comparisons. Run evaluation starts a new job using an explicitly enabled configuration.

Run an evaluation

Choose an enabled test configuration. EvalForge runs both versions and saves the comparison.

1. Check what the documents say

Try a question to see which passages both versions retrieve. This searches your documents using matching words. It does not call AI, generate an answer or decide whether a version passes.

2. Evaluate the AI answers Complete the model setup below, then use Run evaluation. That calls the model and checks its answers against your evaluation rules.
